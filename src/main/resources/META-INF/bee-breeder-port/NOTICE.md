# Bee breeder port

Adapted from the GT Never Reset bee breeder, originally ported from GT-Not-Good under the included MIT license (GTNG-MIT.txt).

Sources: LargeBeeBreeder, LargeBeeBreederGui, LargeBeeBreederRecipes, BeeBreedingHelper, BeeBreedingPlanner, DronePool and the English/Chinese machine descriptions.

Changes: GTNL packages and registration; current MultiMachineBase processing lifecycle, GTNLMultiBlockBaseGui integration and GTNL automatic structure tooltips. Global Forestry mixins are not included.
