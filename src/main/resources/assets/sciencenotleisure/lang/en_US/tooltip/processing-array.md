Allows machines inside to run as if placed in the world.
Place up to 64 GT single-block machines in the controller GUI.
Note that power consumption is the sum of the machines inside.
Use a screwdriver to enable independent input bus functionality.
Invalid for specific machines.
Parallel: number of GT single-block machines * 2 + voltage level * 4 + coil level * 4.
Energy hatch tier cannot exceed the tier of the GT single-block machines in the controller GUI + 4!
