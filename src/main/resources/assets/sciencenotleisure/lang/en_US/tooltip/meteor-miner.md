To function properly, the height of the meteor core must be at least one block higher than the highest point of the multiblock structure.
The laser will mine in a radius of up to 50 blocks in the XZ axis from the center of the meteor
All involved chunks must be force-loaded.
The laser will automatically set its radius based on the meteor.
If no meteor is found, it will wait for a meteor to spawn.
Also considers the block directly above the meteor center.
The reset button can restart the machine without changing the radius.
{red:{bold:Tier I}}
Mines one block per cycle.
Default Fortune level is 0, can be increased by placing special picks in the input bus:
Fortune I: Fiery Pickaxe
Fortune II: Bound Pickaxe
Fortune III: Terra Shatterer
{red:{bold:Tier II}}
Always Fortune III.
Mines a row of blocks per cycle.
Only have 1 ULV Input Bus!
